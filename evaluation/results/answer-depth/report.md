# 답의 근거 설명 늘리기 (2026-10-24)

답이 질문에 바로 답하는 한두 문장에서 끝나고, 그 답이 어느 장면에서 나오는지는 거의 말하지 않았다. 원인은 답 지시문의 길이 기준("대부분 2~6문장, 순서나 목록을 물을 때만 길게")이다. 평가 9회에 응답 시간을 줄이려고 넣은 것이다.

## 바꾼 것

길이 기준을 지우고, 답을 먼저 한두 문장으로 말한 뒤 근거를 보이게 했다.

- 근거가 되는 장면: 몇 화인지, 누가 있고 무엇을 하거나 말하는지. 표현이 중요하면 짧게 인용한다.
- 여러 회차를 잇는 답은 이야기 순서대로 따라가며 앞 회차가 다음으로 어떻게 이어지는지 말한다.
- 답 옆에 둘 맥락: 그 일로 이어진 것, 그 뒤에 일어난 것, 설정 문서나 메모가 그것에 대해 하는 말.
- 원고가 정하지 않은 부분이 질문에 중요하면 마지막에 밝힌다.
- 설명 문장도 모두 읽은 문서에 근거하고 근거 표시를 단다. 질문 되풀이, 줄거리 요약, 묻지 않은 조언은 쓰지 않는다.
- 분량: 단순 사실도 장면과 맥락을 붙여 3~5문장, 여러 회차를 잇거나 이유·방법을 묻는 질문은 5~10문장.

두 번째 안(답·장면·맥락·남은 의문을 번호로 순서 지정, "단순 사실도 최소 1·2부")도 시험했지만 첫 번째 안보다 나은 점이 없어 버렸다.

## 남은 것

- 아주 단순한 사실은 여전히 짧다("선장이 숨진 시각은?" 28 → 76자, 근거 회차 한 줄이 붙는 정도). 두 번째 안으로 더 밀어도 늘지 않았다.
- 군더더기 지적이 4 → 7문항으로 늘었다. 주로 결론을 끝에서 한 번 더 정리하는 문장이다.
- 큰 작품에서 응답 시간이 평균 4초쯤 늘었다.
